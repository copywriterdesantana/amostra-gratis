# Amostra grátis para prospectar · skill grátis para o Claude

Mensagem fria pedindo reunião quase ninguém responde. Mensagem que já entrega uma parte do trabalho, feita com o material do próprio cliente, é diferente: a pessoa vê o que você faz antes de você pedir qualquer coisa.

Esta skill é para quem presta serviço a negócios digitais: dev, designer, copywriter, editor de vídeo, social media, gestor de tráfego. Um cliente por vez, ela:

1. Lê o que é público do possível cliente (perfil, link da bio, página de vendas).
2. Faz um **diagnóstico de 5 minutos**: o que está funcionando e até duas oportunidades que o seu serviço resolve.
3. Produz a **amostra**: uma parte real do serviço, em até 30 minutos, útil mesmo que ele nunca contrate.
4. Escreve a **primeira mensagem sem oferta** e dois acompanhamentos curtos.
5. **Registra** o contato numa planilha simples, para você medir o que funciona.

## O que você recebe

```
amostras/
  meu-servico.md          o seu serviço, respondido uma vez só
  registro.csv            todos os contatos, com status e próxima data
  <cliente>/
    diagnostico.md
    amostra.md
    mensagens.md
```

Veja um exemplo completo em [`exemplos/`](exemplos/).

## O que ela não faz, de propósito

- **Não envia mensagens** e não automatiza nada. Quem envia é você, do seu perfil.
- **Não monta lista em massa.** Um cliente por vez, escolhido por você.
- **Não guarda dado pessoal.** Só o nome do negócio ou o @.
- **Não inventa número** ("você está perdendo 40% das vendas") nem promete resultado.
- **Não publica** conteúdo do cliente sem autorização por escrito.

## Instalação

**No Claude Code**

Baixe este repositório e copie a pasta para a pasta de skills do Claude com o nome `amostra-gratis`:

- Windows: `%USERPROFILE%\.claude\skills\amostra-gratis`
- Mac e Linux: `~/.claude/skills/amostra-gratis`

Use sempre a mesma pasta de trabalho, para o `registro.csv` ir acumulando.

**No claude.ai e em outras IAs**

Compacte a pasta num `.zip` e envie na área de Skills (claude.ai), ou cole o `SKILL.md` e os arquivos de `references/` como instrução. Sem pasta de trabalho, você guarda os textos e o registro por conta própria.

## Como usar

Peça do jeito que você falaria:

- "Monta uma amostra para o @negocio"
- "Quero abordar essa nutricionista, olha a página dela: [link]"
- "Faz o diagnóstico do funil desse perfil"
- "Ela respondeu, e agora?"

## Versão completa

A skill prepara uma amostra por vez com você. A versão completa é um app de prospecção feito para o seu serviço: ele lê o perfil público do possível cliente, monta o diagnóstico e a amostra no seu padrão e guarda o registro de todos os contatos, para você e a sua equipe acompanharem.
